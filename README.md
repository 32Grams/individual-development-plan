# Simple Java Socket Server/Client

Чистая Java, без сторонних библиотек. Демонстрация работы блокирующих сокетов.

## Коммиты

### 1-й коммит (Task 2: Blocking Socket)
Клиент и сервер обмениваются сообщениями по простому текстовому протоколу. Клиент отправляет `"Hello"`, сервер отвечает `"Hi"`. Далее клиент может вводить любые сообщения — сервер молча ждёт, пока клиент не отправит `"Hi"`. Только после получения `"Hi"` сервер закрывает соединение. Если клиент с самого начала отправил не `"Hello"`, а что-то другое — сервер ничего не отвечает, но держит соединение открытым и ждёт `"Hi"` от клиента. Сервер работает на порту 8081 и обслуживает клиентов последовательно.

## Компиляция и запуск

### Компиляция
```
mkdir out
javac -d out src/task2/BlockingEchoServer.java src/task2/BlockingEchoClient.java
```
### Запуск сервера 
```
java -cp out task2.BlockingEchoServer
```
### Запуск клиента
```
java -cp out task2.BlockingEchoClient
```
### Протокол взаимодействия
1. Клиент: `Hello`
2. Сервер: `Hi`
3. Клиент вводит сообщения, пока не введёт `Hi`
4. Сервер закрывает соединение
