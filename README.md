# Simple Java Socket Server/Client

Чистая Java, без сторонних библиотек. Демонстрация работы блокирующих сокетов.

## Коммиты

### 1-й коммит (Task 2: Blocking Socket)
Клиент отправляет `"Hello"`, сервер отвечает `"Hi"` и ожидает подтверждения `"Hi"` от клиента, после чего закрывает соединение. 
Сервер работает на порту 8081 и обслуживает клиентов последовательно.

## Компиляция и запуск

### Компиляция
```
mkdir out
javac -d out src/Server.java src/Client.java
```
### Запуск сервера 
```
java -cp out Server
```
### Запуск клиента
```
java -cp out Client
```
